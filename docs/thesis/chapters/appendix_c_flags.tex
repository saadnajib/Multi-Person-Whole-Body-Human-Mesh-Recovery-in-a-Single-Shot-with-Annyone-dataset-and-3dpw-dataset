\chapter{Flags and weights}
\label{app:flags}

This appendix lists the command-line flags I passed to the training script, so that each run can be repeated.
Table~\ref{tab:flags-final} covers Final and Control. The Student of Section~\ref{sec:method-student} and the
60-epoch run of Section~\ref{sec:res-training-length} share Table~\ref{tab:flags-student}. The temperature sweep of
Section~\ref{sec:res-kd-temperature} has its own, Table~\ref{tab:flags-sweep}.

I list a flag when its value differs from the default in the code, or when it keeps the default but matters for the
result. Every other flag keeps its default. The loss weights are in Table~\ref{tab:loss-weights} of
Chapter~\ref{ch:method}. The commands that start Final, Control and the Student are in the file
\path{docs/thesis/REPRODUCE.md} of the repository (Appendix~\ref{app:reproduction}). I started the 60-epoch run with
\texttt{EPOCHS=60} in front of the same Student command, and the sweep with
\path{slurm/experiments/exp9_kd_temperature.sh}.
