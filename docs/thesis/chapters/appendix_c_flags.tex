\chapter{Flags and Weights}
\label{app:flags}

This appendix lists the command-line flags of the training runs of Final and Control (Table~\ref{tab:flags-final})
and of the Student (Table~\ref{tab:flags-student}) that differ from the default in the code, or that matter although
they keep it; every other flag keeps its default. The loss weights are in Table~\ref{tab:loss-weights} of
Chapter~\ref{ch:method}, the commands that start the runs in the file \path{docs/thesis/REPRODUCE.md} of the
repository (Appendix~\ref{app:reproduction}).
