\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Human mesh recovery estimates a person's 3D body from an image. In this thesis, I study how to make a
multi-person model smaller and faster while keeping useful reconstruction accuracy. I use the Multi-HMR
framework with Anny, a body model with named shape controls such as age, height and proportions.
A smaller ViT-B student learns from a larger ViT-L teacher through knowledge distillation.

The training data combine synthetic AnnyOne images with real images from 3DPW. These datasets use different
body models, so I fit Anny bodies to 3DPW's source joints before training. The corrected label set contains
\DataThreeDPWTotalImages{} images and \DataThreeDPWTotalPeople{} labelled person instances. The teacher uses
\DataMixThreeDPW\,\% real images, consistent head-anchor targets and fixed corrections for selected bone
rotations. The student learns from these labels and from the teacher's features and body predictions.
A trainable projector connects the smaller encoder to prediction heads copied from the teacher.

The student has \StudentParams\,million parameters and requires \StudentGFLOPs\,GFLOPs for the recorded
one-person input, compared with \FinalParams\,million and \FinalGFLOPs\,GFLOPs for the teacher. In a paired
L40S benchmark, a forward pass takes \StudentMsLFortyS\,ms for the student and \TeacherMsLFortyS\,ms for the
teacher. This saving comes with higher reconstruction error. Student PVE is \StudentPVE\,mm on the synthetic
holdout and \StudentThreeDPW\,mm on converted 3DPW; the teacher reaches \FinalPVE\,mm and
\FinalThreeDPW\,mm. The student improves on the released baseline's \NAVERThreeDPW\,mm 3DPW PVE, although
the baseline did not receive the same 3DPW training. Its synthetic result may include images seen in training.

I also compare the models on a walking video and add optional output smoothing and landmark-based alignment.
These steps use the trained student without retraining it. The original comparison records a tracked person
in all \VideoFrames{} student frames and \VideoBaselineMatched{} baseline frames. These counts show coverage,
not 3D accuracy. The main limitations are the student's accuracy gap, unreliable child proportions on real
photos and remaining placement errors. All 3DPW reconstruction scores use fitted Anny labels, so they cannot
be compared directly with published SMPL-space scores.
